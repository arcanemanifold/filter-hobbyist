# Filter Hobbyist

This is a port of the wonderful (if janky) TI Filterpro 2.0 to a standalone html file. A bit of an experiment for me in seeing how fast modern LLM coding tools can port old software. (Compelling, scary, undeniably pretty useful.)

I always found the workflow to be quite friendly, and I like the granularity of editing component values. The more modern web tools were always too much on rails for my liking.
